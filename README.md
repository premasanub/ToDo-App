💰 Income Expense Calculator (Tailwind CSS)
📌 Description
A simple Income Expense Tracker built using HTML, Tailwind CSS, and JavaScript. It supports full CRUD operations and stores data in localStorage.
🚀 Features
Add income & expense
Edit entries
Delete entries
Filter (All / Income / Expense)
Total Income, Expense & Balance
LocalStorage persistence
Responsive UI (Tailwind CSS)
🛠️ Tech Stack
HTML
Tailwind CSS
JavaScript
▶️ How to Run
Download files
Open index.html in browser
💾 Storage
Uses browser localStorage to persist data.
📱 Responsive
Works on mobile and desktop.
